search4vuln

Pick a vulnerability and a scope, then open ready-made GitHub code search queries that find repos referencing possibly affected runtimes.

These results are a candidate list, not confirmation of exposure. A match means a repo references a runtime version that could be affected. Floating tags move, bundled JDKs and vendor products are invisible, and the real runtime is decided by CI, the base image or the host. Verify built images and hosts with java -version, jcmd <PID> VM.version, php -v, or an image scanner or SBOM.

Queries use GitHub code search syntax. Nothing is sent anywhere except the GitHub search page you choose to open. Source: felickz/search4vuln.
